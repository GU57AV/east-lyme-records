## How to read this

- **Meeting days** are dates when the Town calendar, an agenda or minutes show the board meeting. A hearing and a meeting on the same date count once, and cancelled meetings are left out.
- **Agenda found** counts an agenda or notice on the board's pages, or one linked from the Town calendar.
- **Agenda 24 h ahead** and **minutes within 7 days** count only meetings where the posting time could be judged. For documents that appeared after this archive started watching, the archive's own checks show when they went up. For older files the server's file date is used: that is when the file was uploaded, and a file replaced later (for example draft minutes replaced by the approved version) shows the later date. When the Town website's upload folder shows the file first went up in an earlier month, that month is used instead, or the timing is left out if it can't settle the question. Even so, older figures can make a board look slower than it was.
- **Draft minutes may not show.** If draft minutes were posted on time and later deleted when the approved version went up under a new file name, only the later file can be seen here (the archive can't see files removed before it started watching). "Current minutes file uploaded after N days" means the file online now; the Wayback Machine may show whether an earlier draft existed.
- **Minutes found** counts only meetings more than eight days ago. A meeting that was announced but not held can show as missing minutes.
- **Open flags** are this run's [deadline flags](compliance.md) for that board.
- Town meetings are not scored: they are called by a published warning under different rules.
- Boards still being imported will appear once their history is complete.
