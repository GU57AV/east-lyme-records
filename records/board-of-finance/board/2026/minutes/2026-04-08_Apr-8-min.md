6-2. Public Safety Building Server Replacement (Capital Projects)

    Note Dr. McCallister noted that IT Director Dan Cleary has updated information, including a combined
   presentation on the servers and town hall security cameras.

    Note Mr. Cleary came forward and highlighted some of the following:


    Note *Technology costs have increased significantly since the pandemic, with a sharper spike beginning in
   late 2024 and especially 2025, driven largely by new AI data centers.
   *AI data centers demand massive quantities of servers, memory, and hard drives, and are willing to pay
   premium prices, which drives up costs for everyone else.
   *In his 25 years working in IT procurement, he has never seen prices behave the way they have in the last
   two years.
   *Unlike the past when technology got cheaper over time, older tech is now actually becoming more
   expensive than when it was first purchased.
   *Rising costs are also being driven by broader supply chain issues, including higher manufacturing costs
   and shortages of key materials like silver and gold used in electronics production.
   *Helium prices are increasing, partly due to its use in cooling systems and semiconductor manufacturing.
   *Helium supply has been tightened by global disruptions, including geopolitical conflict in the Middle East,
   (the Iran-related conflict), which has impacted production and transport routes and added pressure to
   already limited supply chains.

    Note *A server memory upgrade that cost about $250 in late 2024 had risen to over $1,000 by March
   2026, a four-times increase for the same part.
   *Hard drive prices, while not rising as dramatically, have increased instead of decreased over time,
   something that is highly unusual based on his experience in the IT field.

    Note Dr. McCallister asked if the server replacement was due to a flood or water damage. Mr. Cleary
   clarified it was actually a fire- the UPS (backup power supply) caught fire. The server replacement had
   already been planned since October, before the fire occurred. The fire only damaged the UPS units.

    Note Dr. McCallister asked what would happen if the project was not approved.


    Note Mr. Cleary responded with some of the following remarks:
   *The current servers are already heavily used, running at about 90% capacity overall, mainly in CPU and
   memory, with storage at about 60%.
   *The system is now at the point where one server alone can no longer handle all operations.
   *When the system was first installed, the vendor recommended three servers, but only two were purchased
   due to budget limits.

    Note *At that time, one server could handle the full workload while the second acted as backup.
   *That is no longer the case.
   *Now, if one server fails, critical services would be impacted and non-essential functions would need to be
   shut down, potentially limiting Dispatcher access during outages.
   *The new three-server design would restore proper redundancy, meaning two servers would handle
   operations while the third serves as backup, allowing maintenance or failures without any downtime.

    Note Dr. McCallister asked why a new storage array is needed if storage is only at 60%.


    Note Mr. Cleary explained that the town does not currently have a shared storage system (SAN). Instead,
   each server has its own internal storage, meaning data is tied to individual machines. The new storage
   array would centralize all data so that every server can access it. This means if one server fails, the system
   keeps running on the remaining servers without interruption.
